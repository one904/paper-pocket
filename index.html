从一封信开始

  1. 设置 → 新建 API 配置，填写地址、Key 和模型。
  2. 档案 → 创建角色并复制通讯号。
  3. 聊天 → 注册本地账号 → 用通讯号加好友。
  4. 发送消息后等待 3–10 秒；继续发消息会重置等待。
  5. 长按气泡可编辑、删除、重说；Ctrl / Command + Enter 发送。
  6. 世界书在角色档案里绑定；记忆在阈值达到后自动总结。
  7. 定期导出备份。更换浏览器、清除站点数据会丢失本地记录。

本版实现与边界

• 单 HTML + 内置 Vue 3；界面可离线打开，AI 请求需要联网。 • 桌面支持长按、指针拖动、交换、跨页及 Dock；交换不是连续自动让位。四列小组件保持固定布局。 • 聊天窗口限制渲染最近 100 条，可向前翻阅；不是变高列表的完整虚拟滚动。 • 支持 OpenAI / Anthropic 文本接口、模型拉取与记忆下钻工具；需要服务端允许跨域。 • 切换应用后可继续请求；系统冻结网页、熄屏或关闭浏览器时无法保证后台执行。 • AI 总结可增改合并记忆，合并会重定向历史来源；移除记忆只支持手动操作，避免误删。 • 支持朋友圈与邀请评论；扩展应用请见上方移植范围，不含论坛、生图和图片识别。 • 视觉/生图能力标签用于保存配置元数据，本版不调用图片端点。 • 不要求模型输出私有思维链。模型自带的 think 标签仅兼容过滤，不作为内部思考展示。 • 本地密码使用加盐摘要；API Key 与导出备份仍是明文，勿分享备份。 • 自定义桌面 JS 是显式执行的可信扩展，具有本页权限；仅导入你理解的代码。

关于联网和隐私

聊天内容将发送到你配置的 API 服务。IDB 数据不会自动上传。HTTPS 站点通常不能调用 HTTP 接口；跨域问题需要服务端或可信代理解决，不是按钮故障。HTML 文件路径、部署域名不同会对应不同存储分区。
